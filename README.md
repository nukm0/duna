# Дюна — грузоперевозки

Адаптивный сайт транспортной компании: калькулятор, тарифы, направления со скидкой, форма заявки.

## Запуск

Нужен Node.js 22.13+ и pnpm.

```sh
pnpm install
pnpm dev
```

Локальный адрес: http://localhost:5173.

```sh
pnpm build
```

Проект использует React, TypeScript и Next.js. Серверная часть заявки работает в Node.js на Vercel. GitHub Pages не выполняет обработчик почты.

## Почта

В защищенных переменных окружения сервера задайте:

- `RESEND_API_KEY` — ключ почтового сервиса Resend;
- `ORDER_EMAIL` — адрес компании для заявок;
- `MAIL_FROM` — отправитель с подтвержденного в Resend домена.

Секреты нельзя помещать в репозиторий или клиентский код. В текущем состоянии отправка не подключена: сервер возвращает понятную ошибку, а не ложное подтверждение. Письмо компании содержит контакты, маршрут, груз, дату, комментарий и стоимость, заново вычисленную сервером. Автоматическое письмо клиенту пока не включено.

## Тарифы и допущения

Источник — предоставленная заказчиком фотография. До уточнения приняты следующие правила:

- До 10 км — 3 000 ₽; свыше 10 до 40 км — 150 ₽/км; до 100 км — 102 ₽/км; до 150 км — 72 ₽/км; до 300 км — 66 ₽/км; свыше 300 км — 54 ₽/км.
- Ставка применяется ко всему расстоянию, минимальный базовый заказ — 3 000 ₽.
- После основного расчета применяется скидка 30% на направления Мурманск → Петрозаводск / Санкт-Петербург / Москва и Петрозаводск → Санкт-Петербург / Москва. Обратные направления автоматически скидку не получают.
- На границах используется нижний диапазон: 40 км — 150 ₽/км, 100 км — 102 ₽/км и т.д. Переходы тарифов могут уменьшать итоговую стоимость: это следствие исходной таблицы.
- Километраж вводится вручную, карта и автоматическая маршрутизация не подключены. Значение при открытии калькулятора — пример, его нужно заменить на фактическую длину маршрута.
- Ограничения: 2 000 кг и 10 м³. Размеры кузова 4 × 2 × 2,2 м с фото не согласуются с объемом 10 м³ — требуется уточнение.
- Стоимость предварительная. Данные компании и получатель писем еще не предоставлены.

Основная формула: `app/pricing.ts`. Обработчик заявки: `app/api/request/route.ts`.

## Развертывание в Vercel

1. В Vercel выберите Add New → Project и импортируйте репозиторий nukm0/duna.
2. Framework Preset: Next.js; Root Directory: корень репозитория. Build Command: pnpm build. Output Directory: автоматический.
3. В Settings → Environment Variables добавьте RESEND_API_KEY, ORDER_EMAIL, MAIL_FROM для Production (и Preview, если там нужна отправка).
4. Нажмите Deploy; после изменения переменных выполните Redeploy.
5. Откройте сайт, выполните расчет и отправьте тестовую заявку. Проверьте письмо в ящике получателя и журнал Resend.

Локально значения переменных можно хранить в .env.local (не отслеживается Git).

Прежние файлы запуска Sites/Cloudflare сохранены как вспомогательные; основной запуск и сборка теперь используют Next.js.

## Проверенные действия интерфейса

- Меню навигации и мобильное меню ведут к соответствующим разделам.
- Карточки услуг выбирают тип перевозки в калькуляторе; тип включается в письмо.
- Популярные направления заполняют города и сбрасывают километраж, чтобы старое расстояние не использовалось для другого маршрута.
- Кнопка карты открывает маршрут в Яндекс Картах; расстояние пользователь переносит вручную.
- Очистка сбрасывает поля; скачивание сохраняет текстовый расчет.
- Заявка открывает диалог с текущим расчетом; проверяются обязательные поля и согласие.
- Вопросы и ответы раскрываются по нажатию.

Для фактической отправки заявки по-прежнему нужны RESEND_API_KEY, ORDER_EMAIL и MAIL_FROM.

Выбор перевозки: «Отдельная машина» — расчет по тарифам для 2 тонн и 10 м³; «Сборный груз» — стоимость по согласованию. Выбор передается в заявку и скачанный расчет.

## Карта маршрута и сборные грузы

Кнопка «Построить маршрут» использует JavaScript API Яндекс Карт 2.1, показывает автомобильный маршрут и заполняет километраж из длины активного маршрута. Старое подключение OSRM/Photon больше не используется. При недоступности API можно ввести расстояние вручную. Автомобильный маршрут требует проверки грузовых ограничений.

«Отдельная машина» показывает карточки транспорта, «Сборный груз» заменяет их редактором грузовых мест. Размеры в сантиметрах; вес одного места — в граммах, килограммах или тоннах. Общий вес и объем умножаются на количество. Доступны добавление/удаление мест, вращение и штабелирование. При переключении режимов данные сохраняются. Сервер заново рассчитывает итог из мест, а не доверяет клиентской сумме. Стоимость сборного груза — по согласованию.


## Яндекс Карты

В Vercel настроена переменная YANDEX_MAPS_API_KEY для Production и Preview. Локально можно задать ее в .env.local. Значение не хранится в репозитории. JS API использует браузерный ключ: при работе карты он видим в запросах браузера. В кабинете Яндекса ограничьте ключ доменами duna-pi.vercel.app и duna-nukm0.vercel.app. Для локальной проверки при необходимости разрешите localhost. Для маршрутов нужен доступ к маршрутизации JS API; запросы учитываются по условиям Яндекса.
